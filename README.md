# Nuvio & Euthopiar Plugins Repository

This repository contains community scraper plugins for the Euthopiar / Nuvio streaming platform.

## Available Plugins

| ID | Name | Description | Supported Types | Languages |
|:---|:---|:---|:---:|:---:|
| `movy` | **Movy** | Multi-server fast streaming provider powered by movy.sx (Miami, Boise, Atlanta, Phoenix, Vegas, Reno, Oakland, Seattle, Dallas, Berlin, Paris) | Movie, TV, Anime | EN, DE, FR, ES |

## How to Install in App

1. Open the **Euthopiar** or **Nuvio** app on your Android device.
2. Go to **Settings** > **Plugins** (or **Scraper Repositories**).
3. Click **Add Repository** and paste the manifest URL:
   ```text
   https://raw.githubusercontent.com/TheARCreactorGUY/Plugins/main/manifest.json
   ```
4. Click **Install / Add**. The Movy plugin will be downloaded and enabled automatically.
